# ProjectMoonBase
ProjectMoonBase is a moveset base for the Roblox game Jujutsu Shenanigans.

## Features
- Automated installer, just paste your moveset code then it will automatically add all of the PMBase skills.
- Automated updater, just paste your moveset which currently has an outdated version of PMBase then it will replace the outdated skills and keep the config.
- Simple configuration, a single skill with tags for easy configuration.
- A lot of statuses supported, with potency and count.
- Support for both Limbus Company and Library Of Ruina UI and Statuses (LoR is WIP)

## Updating and installation
Go to the [ProjectMoonBase website](pmbase.oxygenlow.com), paste your moveset code, then it will automatically install without you needing to manually copy and paste every branch manually.

Similar way for updating, just click on the update tab, paste the moveset and it will preserve your PMBase config (if the update includes modified or new config tags it will modify it).

## Why?
There's no moveset base for Project Moon movesets that contain almost all of the statuses, good ui, simple update + install, and easy configuration.
